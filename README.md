# Streak downloads

Streak is a personal daily todo app built around streaks. This page only hosts the installers.

**Latest version:** see [Releases](../../releases/latest). The first public build is coming soon.

## Install

**Windows** (10 or 11): download `Streak-Setup-<version>.exe` and run it. It installs for your user only and needs no admin
rights. The installer is not code-signed, so Windows SmartScreen may say "Windows protected your PC": click
*More info*, then *Run anyway*.

**Android** (7.0 or newer): download `Streak-<version>.apk` on your phone and open it. Android will ask you to allow
installs from the app you opened it with (your browser or Files app): allow it for this once. To update, download the
newer file and install it over the old one. Do not uninstall first.

There is no iPhone or Mac version.

## Notes

- The app works offline and keeps its data on your device.
- Each release lists the files for that version. Only install files that come from this page.
